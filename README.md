# Kitty Cat (PWA)
Plain HTML/JS app for Piccadilly line train drivers at Arnos Grove and Cockfosters. Install from Chrome on Android with Add to Home screen.

Contains **no duty data**. Each driver loads the PDFs they have been issued (duty book, notices, running cards) with Load PDFs or Share › Kitty Cat; they are read on the phone and stay in that phone's storage only.

pdf.js is vendored under `vendor/` (Apache-2.0, see `vendor/PDFJS-LICENSE`).
