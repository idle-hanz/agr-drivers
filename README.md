# AGR Drivers (PWA)
Plain HTML/JS app for Piccadilly line train drivers at Arnos Grove. Install from Chrome on Android with Add to Home screen.

Contains **no duty data**. Each driver loads the PDFs they have been issued (duty book, notices, running cards) with Load PDFs or Share › AGR Drivers; they are read on the phone and stay in that phone's storage only.

pdf.js is vendored under `vendor/` (Apache-2.0, see `vendor/PDFJS-LICENSE`).

Optional: a free TomTom key (developer.tomtom.com) entered in Settings gives traffic-aware drive times. It is stored on the phone only.
